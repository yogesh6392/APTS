About the Capstone Management System

Academic Project Documentation • Engineering Problem Definition • Scope

🎯 Project Problem

Traditional academic capstone reviews suffer from untracked email submissions, scattered documentation files, untraceable revision cycles, and subjective evaluation rubrics lacking transparent criterion marks.

💡 Proposed Solution

A centralized, role-based web platform integrating candidate project submissions, permanent asset storage (PDF specs, PPT slides, Git code), 7-stage milestone state machines, and a faculty 100-mark rubric evaluator.

🚀 Objectives & Scope

1. Enforce phase-gate review governance (Draft → Submitted → Review → Resubmission → Viva → Grade).
2. Maintain multi-version provenance ledgers preventing duplicate project records.
3. Deliver standardized marks evaluation and CSV audit dossiers.
